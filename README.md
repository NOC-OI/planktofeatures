# planktofeatures
A Python library for calculating features of plankton images captured on the IFCB. Wraps [WHOI ifcb-features](https://github.com/WHOIGit/ifcb-features) as a user-friendly PIP-installable package.

> [!NOTE]
> This repository requires submodules to function, make sure to use `--recurse-submodules` if cloning the repo!

# Install via PIP

For most people, installing from PIP is the simplest way to start using planktofeatures:
```
$ pip install planktofeatures
```

# Additional test dependencies
You will need libifcb to run the test script in addition to the other dependencies for planktofeatures.
